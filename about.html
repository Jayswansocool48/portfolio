About

I’m Jason, a game developer and 3D artist. Iron Lantern Studios is the name I put on my work.

I’ve been making games and assets since 2020. Most days I’m in Unity or Blender, modeling props or tuning a level until it feels right.

I started in Roblox Studio, learned to code, took a break, and came back with a list of games I had to make. This site tracks every one of them.

How I got here

  1. 2020
    First steps

    I started in Roblox Studio and left a trail of unfinished projects behind me.

  2. 2021
    Learning to code

    I picked up Lua and Python and learned how program logic fits together.

  3. 2023
    Reset

    I stepped away from code for a while and came back wanting it more.

  4. 2024
    Web design

    I learned HTML and CSS through Codecademy and built my first small site.

  5. 2025
    Crazy Taxi

    I started my first full game project and began modeling its city.

  6. 2026
    After Hours

    I started a horror game and rebuilt this site from scratch.
